# Código de conducta

Este proyecto sirve a la comunidad de CTF y seguridad ofensiva. Se espera
de todo colaborador:

- Trato respetuoso en issues, PRs y discusiones, sin importar nivel de
  experiencia.
- Reportes de bugs centrados en el problema técnico, no en la persona.
- Cero tolerancia a solicitudes o contribuciones orientadas a facilitar
  ataques contra objetivos no autorizados (ver `LEGAL.md`). Cualquier
  issue/PR que pida ayuda para atacar un objetivo real sin autorización
  será cerrado.

Las violaciones pueden reportarse abriendo un issue marcado como
`conduct` o contactando directamente a los mantenedores del repositorio.
